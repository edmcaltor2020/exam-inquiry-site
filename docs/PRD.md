# 사이트 설계도(PRD) — (이름 미정) 건강검진·영상검사 병원

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
증상이 있어 검사가 필요한 환자가 진료 종류와 검사를 직접 골라 문의할 수 있는, 건강검진·영상검사 중심 병원의 한 장짜리 사이트.

## 2. 손님
- 누가: 증상이 있어 검사가 필요한 환자
- 어디서 알고 오나: 네이버·구글 검색

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 검사 비용
2. 예약·대기 시간
3. 검사 전 준비사항

## 4. 믿게 할 증거 (실제로 있는 것만)
- 의료진 약력·전문의 자격 (사용자가 제공한 내용만 적는다)
- 장비·검사실 사진 (사용자가 제공한 사진만 쓴다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 검사 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로) — 1페이지
1. 첫 화면 — 한 문장 + [검사 문의하기] 버튼
2. 진료 종류·검사 고르기 — 진료 종류를 고르면 해당 검사가 보이고, 여러 개 선택할 수 있다. 고른 항목은 문의 폼에 자동으로 들어간다. (목록 내용은 미정 — 아래 8번 참고)
3. 검사 전에 궁금한 것 — 비용 · 예약·대기 시간 · 검사 전 준비사항 (내용은 사용자가 알려 준 것만, 없으면 "준비 중")
4. 의료진 · 검사실 (약력·자격, 장비·검사실 사진) / 후기 자리 (비워 둠)
5. 문의 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 한 줄 문의 내용 (증상 같은 민감한 내용은 적지 말라고 안내)
- 고른 진료 종류·검사 (자동으로 채워짐)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 병원 이름: (미정 — 임시 이름 사용)
- 진료 종류·검사 목록: (미정)
- 가격: (미정)
- 시간: (미정)
- 위치: (미정)
- 연락 방법: (미정)

## 9. 이번에 넣지 않을 것
- 실시간 예약 확정 (이번에는 문의만 받는다)
- 회원가입·로그인
- 결제, 사진 올리기, 알림 메일

## 10. 첫 화면 한 문장 후보
1. 어떤 검사가 필요한지, 직접 골라 문의하세요.
2. 증상에 맞는 검사를 고르고 편하게 물어보세요.
3. 검사 비용과 준비사항, 문의 한 번으로 확인하세요.

## 11. 다음에 할 것
- 실시간 예약 확정
- 회원가입·로그인 (필요해지면 개인정보 처리방침 함께 준비)
- 병원 이름·주소·진료시간·전화·가격 채우기 (미정 항목)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
